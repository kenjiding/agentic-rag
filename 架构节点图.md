flowchart TD
    UserQuery[用户提问] --> ContextManager[Context Manager 节点]
    
    ContextManager -->|构建统一上下文| Planner[Planner 节点]
    
    Planner -->|Single-Shot规划| PlannerOutput{Planner输出}
    PlannerOutput -->|1. query_intent| IntentData[意图识别 + 实体提取]
    PlannerOutput -->|2. plan| PlanData[多步骤执行计划]
    
    PlanData --> PolicyGate[Policy Gate 节点]
    PolicyGate -->|风险评估| PlanExecutor[Plan Executor 节点]
    
    PlanExecutor -->|检查当前步骤| StepType{步骤类型?}
    
    StepType -->|agent_call| AgentExecution[执行Agent]
    StepType -->|ask_user| UserInterrupt[用户确认/输入]
    StepType -->|finish| End[结束]
    
    AgentExecution -->|执行完成| PostVerifier[Post Action Verifier]
    PostVerifier -->|验证通过| PlanExecutor
    
    UserInterrupt -->|用户响应| PlanExecutor
    
    PlanExecutor -->|有更多步骤| StepType
    PlanExecutor -->|计划完成| End
    
    Planner -->|失败| Supervisor[Supervisor fallback]
    PlanExecutor -->|plan=None| Supervisor
    Supervisor --> AgentExecution
